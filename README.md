# 🌐 VIPD.SHOP — Web Downloader Application

نسخة الويب المستقلة لمنصة **VIPD.SHOP** المخصصة للعمل على جميع متصفحات الويب وأجهزة الكمبيوتر والجوال.

## 🌟 المميزات
- تعمل على أي متصفح (Chrome, Safari, Firefox, Edge, Opera).
- مدعومة بخادم REST API مستقل ومبني بـ Express Server.
- تستدعي المحرك الفعلي `yt-dlp` و `ffmpeg` للتنزيل بدقة 4K / 1080p / MP3.
- تدعم سلسلات التنزيل والسجل واختيار الجودات والقص وتنزيل الغلاف.

## 🚀 التشغيل المباشر
1. تشغيل الملف المباشر: `START_WEB.bat`
2. أو عبر Node.js:
```bash
cd B:\VM-Web
npm start
```
سيتم فتح التطبيق تلقائياً على العنوان: `http://localhost:3000`
