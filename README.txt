VM Downloader - Portable (Windows)

IMPORTANT:
- All command files use ENGLISH names only (CMD-safe).
- Unzip with Windows Explorer or 7-Zip.

Commands (double-click):
  1) INSTALL_TOOLS.bat
  2) CREATE_DESKTOP_SHORTCUT.bat
  3) VM.exe
  Optional:
     RUN_MENU.bat
     SHOW_GUIDE.bat

Guide images (in order):
  guide-images\1-what-vm-does.png
  guide-images\2-how-vm-works.png
  guide-images\3-install-steps.png

Requirements:
  Windows 10+
  Internet for first setup
  Node.js (installed by INSTALL_TOOLS.bat if missing)
