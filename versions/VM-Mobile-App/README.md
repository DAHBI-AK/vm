# 📱 VM Mobile App — Downloader Pro (PWA & Mobile Web Version)

تطبيق مستقل مخصص للهواتف والأجهزة الذكية (Android & iOS).

## 🌟 المميزات
- شريط تنقل سفلي لمسي (Bottom Navigation Bar) مماثل للتطبيقات الأصلية (Native App Feel).
- دعم تثبيت التطبيق على الشاشة الرئيسية للجوال (Add to Home Screen - PWA).
- سرعة عالية وتصميم عالي الأناقة وتجاوب تام للمس.
- تدعم التحميل المباشر وقص المقاطع وسلاسل الروابط والتصاميم المخصصة للجوال.

## 🚀 التشغيل المباشر
- تشغيل `START_MOBILE.bat` وفتح الرابط في متصفح الجوال أو الكمبيوتر.
